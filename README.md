# MUTYINT — Multipurpose Talented Young Inventors & Transformers

Flagship website for MUTYINT, the invention company founded by Emmanuel Ene Rejoice (Erogian).

Live ventures: S.T.E.W Agent, PropelPay, Shazam AI, Slime AI, Erogian, Velora.

## Stack
Zero-dependency single-page site (`index.html`):
- Lenis smooth scrolling (CDN, graceful fallback)
- Scroll-driven manifesto word lighting, sticky stacked venture cards
- 3D tilt + spotlight cards, magnetic buttons, custom cursor
- Film-grain overlay, aurora parallax, cinematic preloader
- Fully responsive, `prefers-reduced-motion` respected

## Deploy (Vercel)
Import this repo at https://vercel.com/new — no build step, no settings needed.
Or with the CLI: `vercel --prod`
