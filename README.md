# MUTYINT — Multipurpose Talented Young Inventors & Transformers

Official multi-page website for MUTYINT, the movement founded by Emmanuel Ene Rejoice (Erogian).
Built from the founder's official MUTYINT document — motto, Ecclesiastes 12:11, the Five Goals,
Vision & Mission, the 12-pillar Mandate, and the Five Departments.

## Pages
- `index.html` — Home: cinematic hero, scroll-lit welcome, chapter hub, stats, founder
- `the-name.html` — The Name & Five Goals (M/T/Y/I/T deep dive)
- `vision-mission.html` — Vision, Mission and the 12-pillar Mandate
- `departments.html` — Engine Room (EGSIN), Goal Setters (Eggint), Society, Influencers, Inventors & Transformers
- `ventures.html` — Proof of Invention: S.T.E.W Agent, PropelPay, Shazam AI, Slime AI, Erogian, Velora

## Stack
Zero-dependency static site (`styles.css` + `site.js` shared design system):
- Lenis smooth scrolling (CDN, graceful fallback)
- Cinematic preloader with motto, scroll-lit manifesto words, mask-reveal headlines
- Sticky stacked cards, 3D tilt, magnetic buttons, custom cursor, film grain, aurora parallax
- Fully responsive, `prefers-reduced-motion` respected

## Deploy (Vercel)
Import this repo at https://vercel.com/new — no build step, no settings needed.
Or with the CLI: `vercel --prod`
